# TapeOut 3D 实验室（dsh-tapeout-3d-lab）

一个 DeepSeek Harness 的 Web 客户端插件：左侧边栏新增 **「TapeOut 3D 实验室」** 入口，
主面板里是一台**可交互的 3D 演示游戏**，用七章任务讲清 TapeOut 协议的工作原理与内部逻辑——
从一颗 7 字节的与非门 Token，到永远开机的链上 CPU「巨兽」。

## 安装与打开

本包是按 Harness bundle 规范打包的**本地插件包**（不是 npm 上的公开包，没有公开网址）：
它的"地址"就是本机目录 `/Users/loot360/各项目/tapeout/tapeout-3d-plugin`。

**已经安装**到当前 profile（`desktop`，以软链接方式），所以现在就能用：

1. 打开 Web GUI，左侧边栏点 **「TapeOut 3D 实验室」**（图标是一块六边形裸片）。
2. 首次打开会显示**新手引导**：可选「零基础 / 先玩 / 技术」三条路径直达对应入口；之后随时点顶部 **🧭** 重新打开。
3. 章节说明不自动弹出：点顶部 **📖** 按钮可随时打开/关闭；`Esc` 关闭。
4. 实验室页签按 **入门 / 应用实验 / 工程落地** 分组，并带「推荐路径」快捷入口。
5. 顶部工具栏：任务 / 实验室 / 游乐场 三档、提示、重置、镜头、声音、电影模式、协议档案。

### 在另一个 Harness 里安装

方式一（推荐，本地目录）：
1. 把整个 `tapeout-3d-plugin/` 目录拷到目标机器（或解压本仓库附带的 zip）；
2. 打开目标 Harness 的 Web GUI → 左侧 **Plugins** → **Add plugin**；
3. 在输入框粘贴**目录的绝对路径**（例如 `/Users/you/tapeout-3d-plugin`）→ **Install** → **Enable now**；
4. 刷新页面，侧边栏出现「TapeOut 3D 实验室」。

方式二（GitHub 仓库）：

```
https://github.com/Qzy05231/dsh-tapelab.git
```

Harness 的 **Plugins → Add plugin** 支持 Git 地址，粘贴上面的仓库地址即可
（或写成 `github:Qzy05231/dsh-tapelab`）。也可以本地 `git clone` 后用方式一安装。

方式三（tarball）：Add plugin 接受 tarball；本仓库 release 里可直接下载
`dsh-tapeout-3d-lab-1.0.0.zip`，解压后按方式一安装。

方式四（让 Agent 装）：在本会话里说"把 `/绝对路径/tapeout-3d-plugin` 装进当前 profile"，
我会用 `plugin_manager install_bundle` 完成安装并确认 `application: applied`。

### 环境要求

- DeepSeek Harness `>=0.2.1 <0.3.0`（当前运行的是 0.2.2-rc.1）；
- 不需要网络、不需要额外 npm 依赖（React 由 Harness 提供，3D 引擎是自带的 canvas 软渲染）；
- 含 `client.js` 构建产物即可运行；改了源码后运行 `node scripts/build.mjs` 重新生成。

## 七章任务

| 章 | 主题 | 玩家要做什么 | 讲清什么 |
|---|---|---|---|
| 1 | 铸币 · 晶体管 | 点硅片上的芯片，铸出 8 颗 NAND | ERC-1155 Token；一颗 = 7 字节链上记录 |
| 2 | 与非门 · 谁都能算 | 放入与非门、接 A/B、点输入板试遍 4 种组合 | NAND = NOT(A AND B)；一种门即可构成所有计算 |
| 3 | 半加器 · 五颗晶体管 | 放 5 个门、接 12 根线（可让助手逐根接）、穷举验证 | SUM=异或、CARRY=进位；5 颗晶体管会算加法 |
| 4 | 流片 · 蚀刻成 NFT | 点「流片」看 Token 销毁、字节码逐门写入、NFT 水晶成形；再做免费 eval | 电路 = ERC-721；逻辑是数据不是代码；只读求值免费且无副作用 |
| 5 | 时钟 · 记忆 | 拉低 S/R 并保持，观察两个节拍后的瞬态与稳定，让 Q 稳定 3 拍再复位 | 锁存器/一位状态；0.45 秒出块 = 2.22 Hz 心跳；交叉反馈的真实时序 |
| 6 | 乐高 · 黑盒复用 | 放入两个已流片半加器 + 一个或门，接 8 根线、验证 8 行、流片 | 黑盒复用；复用版 13 门 vs 手工优化 9 门的取舍 |
| 7 | 巨兽 · 链上 CPU | 点「运行 3 + 5」，看四位加法器逐位进位、七段显示器亮起 | 出块驱动 CPU；2300 晶体管、2.22 Hz、工厂放弃权限、永不关机 |
| 8 | 七段译码器 · 100 颗晶体管 | 用自动综合器造出 4→7 译码器、穷举 16 行、流片、点亮 0–9 | 真值表 → 门级网表 → 流片；综合后 110 个与非门 |
| 9 | 计数器 · 时间的形状 | 手动/自动推进区块，看 4 位二进制从 0000 数到 1111 再回绕 | 4 个锁存器 + 15 门 = 计数器；出块即节拍 |
| 10 | 小计算机 · 跑程序 | 载入三个程序，按区块单步/运行，看 PC、IR、A、OUT 与 3+5 / 累加 / 乘法 | 取指→译码→执行；寄存器 + ALU + 程序计数器 |
| 11 | 安全电路 · 真实项目联动 | 拨 16 个输入，看小车被允许/减速/返航/停车；穷举 65536 组互斥审计 | 嵌入 TapeRover 真实的 16 输入 / 80 门安全网表 |

全局：链上区块高度持续增长（暂停只冻结演示，不能暂停链）、NAND 余额、已流片电路、
网表十六进制、穷举验证行、只读 eval 结果、锁存器波形都在右侧数据面板里。

## 实验室（顶部「任务 / 实验室」切换）

- **综合器**：真值表（支持 0 / 1 / 无关项）→ Quine–McCluskey 化简 → NAND 网表；
  显示门数 / 文字量 / 项数 / 16 进制字节码，并自动穷举验证；可存进电路库或送进沙盒。
- **元件展厅**：NOT/AND/OR/XOR/NAND/MUX/2-4 译码器/半加器/全加器/SR 锁存器/计数器/
  七段译码器，共 12 件；门数取实网表，点「沙盒打开」看真实 NAND 网表。
- **3D 电路沙盒**：任何网表都能在 3D 里展开成门阵列 + 导线 + 输入板 + 输出 LED；
  点击输入板实时驱动求值，可旋转缩放。
- **电路库**：最多保存 24 个电路（localStorage 持久化），随时载入沙盒或删除。
- **成就墙与街机记录**：16 个徽章（主线 / 贪吃蛇 / 排障 / 综合 / 猜数 / 密码锁 / 每日挑战），
  顶部 🏆 打开，记录自动保存在本机；达成时弹提示；可**生成 PNG 分享卡**或复制战绩文本。
- **第一章 / 第四章变体挑战**：第一章挑战按固定顺序铸币（错序计失误）；
  第四章挑战流片前连答「门数 → 燃烧数量 → 引脚配置」三问（答错计失误）。
- **关键操作不再「一键通关」**：第一章需先手动铸 2 颗才能用「一键铸满」；
  第四章流片前要回答「半加器几颗门」的检查题（答错在挑战模式计失误）。
- **章节挑战模式（⚡）**：任务卡里随时在「正常 / 挑战」间切换；挑战禁用助手与一键快捷，
  同时考核 **用时 + 操作预算 + 失误**（3★ 需金标时间内、用完预算内且零失误）；
  可随时「重置」本次挑战；最佳星级/用时记录在本机；新增「挑战者」「三星挑战」徽章。
- **每日挑战**：按本地日期确定性生成隐藏 3 输入真值表；题面给 2 行，7 次查询预算，
  补全 8 行真值表提交，查询越少越好（同一天所有人同题，可离线复算）。
- **第 12–14 章（应用章节，5–7 步）**：DeWeb 可验证网站（策略选择 + 篡改校验）、
  TapeRelay 分块/副本策略/节点下线恢复/篡改校验/零 gas 消息、容器化部署（基础镜像、
  NFT 权限、资源限额、镜像校验）；每章有独立 3D 场景、任务清单、操作坞与错误分支。
  篡改的节点/分块/镜像层**每局随机**，可直接在 3D 场景点击检查；错误选择计入失误（影响挑战三星）。
- **生态版图（顶层板块）**：顶部「官方生态」模式里是一张葡萄玻璃质感的彩色气泡图，仅收录 TapeOut 官方入口，仅 6 个 Official 项目（TapeOut / Blonskr / TapeHub.ai / TapeKit / TapeCode.ai / TapeRelay）；
  币圈气泡风格（深色币面 + 彩色发光圆环 + 图标/名称/彩色副标题），随机漂移、可暂停/重排。
- **每日资讯（顶层板块）**：顶部第四个模式「📰 资讯」；实时列表来自 **tapeout.link/news** 的真实抓取
  （构建时经 r.jina.ai 文本代理抓取并嵌入快照），每天 **06:00 自动抓取一次**（应用在 6 点后
  打开或一直运行时触发；手动刷新也会记为当天已抓取），失败每 30 分钟重试并回退本地快照；
  附每日协议速览、今日数据、每日一问与最近更新。
- **Verilog 导入**：沙盒页粘贴 gate-level Verilog（input/output/wire + assign，支持
  `~ & | ^`、位选、常量），自动降级成 NAND 网表并验证；附带 `nand-cli` 命令行。
- **导出与分享**：综合结果/沙盒电路支持复制 **hex / Verilog / JSON / 真值表 CSV**；
  电路库可导出**存档码**（一段文本），换电脑粘贴即可恢复全部电路。
- **DeFi 交易守卫（模拟 AMM）**：滑点/额度/预言机/白名单/暂停 4 位条件编译成 NAND 守卫，
  放行后才在常量乘积 AMM 里成交；支持穷举审计与可复算凭证，明确标注"无钱包、无签名、无链上交易"。
- **传感器规则引擎**：5 个场景（家庭安防 / 火灾联动 / 新风联动 / 工业联锁 / 机房环境），
  模拟量按阈值变成布尔位，综合成**多输出 NAND 电路**驱动报警/断电/喷淋/新风/停机等执行器；
  规则可穷举审计，凭证记录原始读数/阈值/指纹并可离线复算。
- **生成艺术（每区块一帧）**：电路状态（8 位 LFSR / 4 位计数器）驱动确定性画面，
  可播放/单帧推进、导出 PNG、铸造进本地画廊；作品码记录种子/状态来源/区块序号/帧哈希，
  可离线复算验证。
- **可验证抽奖 / 随机数**：公开种子 + 参与者名单确定性选出中奖者；抽奖凭证可离线复算，
  改名字/种子/顺序都会被发现；附带 8 位 LFSR 的电路视角与「种子承诺」安全提示。
- **可验证门禁 / 资格判定**：5 种策略（简单门禁 / 会员+黑名单 / 邀请制 / 多签放行 / 员工临时授权），
  自动综合成 NAND 电路、穷举审计、拨条件看 ALLOW/DENY，并签发**可离线复算的凭证**
  （含策略指纹；篡改输入/结果/电路会被验证器发现）。
- **硬件搭建（74HC00）**：把任意组合网表翻译成**真实面包板方案**——需要几片 74HC00、
  每个门的 A/B/Y 引脚分配（DIP-14 标准引脚）、逐根连线表、BOM（芯片/电阻/电容/LED/开关/面包板）、
  以及可直接下单的采购清单与搭建指南（可复制 CSV / Markdown）；时序电路会明确提示需要额外时钟芯片。

## 交互

- **拖动**旋转镜头，**滚轮/双指**缩放，工具栏 ⌖ 重置镜头。
- **点芯片**铸币；**点输入板**切换 0/1；**点端口**开始连线，再点另一个输入端口完成接线；
  点空白处取消待接的线。

  `Esc` 关闭档案/完成页。面板右上角 ✕ 返回对话。

## 视觉与性能（第二版打磨）

- **中心光斑修掉**：中景那颗「很亮的圆球」来自叠在硅片中心的加性 glow 精灵（半径 5.2、
  强度 0.18，投影后约 350px）。已把中心光斑改为半径 3.0 / 5.5%，并在引擎里显式使用
  `source-over` 合成，避免被其它加性图层叠亮；其它章节的机器光、水晶光、巨兽光也同步调低。
- **场景残留（那根亮柱子）修复**：3D 场景里有一类「无名」装饰物（背景板、流片机光柱、光晕、
  文字、外环）之前没有登记进清场表，切章只清掉有名物件（芯片/端口/门），无名物件会在 canvas
  里累积，于是第 4 章的光柱、第 7 章的裸片与加法器牌会残留到别的章节。现在所有物件统一登记、
  切章统一清场（同时清掉未衰减完的特效），并新增 `tests/world.test.mjs` 回归测试：七章往返
  两轮后场景物件数必须回到基线、特效 1.2s 内回收。
- **HUD 防溢出**：任务卡/数据面板改为按面板宽度取百分比、可滚动、`min-width:0`，窄面板不再把
  右侧数据挤出画面。
- **事件特效**：铸币、每接一根线、验证通过、流片开始/完成、锁存器翻转、CPU 逐位进位、
  单章完成、七章全部完成，都会在世界里炸出对应颜色的冲击波（引擎 ring + glow，约 1 秒衰减）。
- **章节转场**：进入/重置章节有暗场淡入 + 大字章节印章动画 + 相机飞入。
- **氛围**：青色 + 琥珀两层漂浮粒子、硅片外围两道反向旋转的约束环、远景 `TAPEOUT · SILICON LAB` 标识。
- **性能**：场景按「视觉签名」重建（时钟 tick、日志、提示不再触发整场重搭）；导线流动
  每 4 帧更新一次；7 段数码管/流片机精灵直接读取最新状态，不再随每次状态变化重建；
  所有 glow 使用缓存离屏渐变，DPR 上限 2。`prefers-reduced-motion` 下关闭彩带/印章/浮动动画。

## 游乐场（顶部「游乐场」切换）

六个小游戏，全部复用同一套 NAND / 时钟 / 音效系统：

- **NAND 音乐盒**：4 位计数器分频 + 音阶表，用出块当节拍演奏；3 种音阶（大调/五声/小调）、
  4 首曲目（音阶练习/小星星/方波练习/欢乐颂）、三档速度，实时显示当前音与 16 步滚动谱。
- **8×8 LED 点阵**：64 个像素手动点亮，3 个预设图案，可用链上时钟做逐列滚动动画。
- **4 位密码锁**：比较器谜题，每次检查给出每位匹配提示（约 20 颗与非门）。
- **猜数字（LFSR）**：0–15 二进制猜数，大了/小了反馈，最多 8 次；讲清链上伪随机。
- **三人表决器**：多数门（majority），附 8 行真值表。
- **故障排查实验室**：5 个「某根线接错」的电路，看期望 vs 实际真值表差异，
  从 4 个候选修复里选对；覆盖异或、多数门、相等判断、七段段位、奇偶校验。
- **街机难度与记录**：贪吃蛇可选慢/中/快三档并保存本机排行榜；猜数字收紧到 5 次并计分；
  密码锁限 6 次尝试；游乐场顶部显示本机最佳记录。
- **链上贪吃蛇**：8×8 点阵上的蛇，每 0.45 秒（一个区块）走一格；方向键/WASD 控制，
  吃食物加分，撞墙/撞自己结束。面板里解释它的状态寄存器与门级实现。

## 声音与电影模式

- **合成音效**：11 种 WebAudio 振荡器音色（点击、接线、铸币、验证通过、流片、完成、计数滴答、错误……），
  无音频素材、无网络请求；浏览器要求用户手势后解锁，第一次点击/按键自动启用。
  工具栏 🔊 或快捷键 `M` 静音，偏好写进 localStorage。

### 自动抓取的时间点

- **06:00 时应用在运行**：最迟 5 分钟内自动抓取；
- **06:00 时应用没开**：下次打开资讯页（当天 6 点后）自动补抓一次；

## 命令行工具（nand-cli）

```bash
node tools/nand-cli.mjs synth 0110                 # 综合真值表（2、4、8、16 项）
node tools/nand-cli.mjs import circuit.v           # 导入 gate-level Verilog
node tools/nand-cli.mjs import circuit.v --json > n.json
node tools/nand-cli.mjs eval --file n.json --in 11 # 只读求值
node tools/nand-cli.mjs verify --file n.json       # 穷举验证
node tools/nand-cli.mjs disasm --file n.json       # 列出每个门
```

支持且仅支持组合逻辑子集：`input/output/wire`、`assign`、`~ & | ^`、括号、`a[0]`、
`1'b0/1'b1`；不支持 `always/reg/算术`。网表 JSON 与实验室「复制 JSON」格式一致。
